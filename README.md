# 智能地质测井数据分析与可视化系统 (Well Log Data Analysis System)

## 项目概述
本项目旨在开发一款聚焦点于地质测井方向的TXT数据解析、过滤、可视化展示及导出的Web端管理系统。系统结合现代化科技感的企业后台UI设计，突破性地提供专业的测井数据快速检索引擎、多通道并发比对比可视化、AI智能提取等核心地勘业务能力。

## 核心特性
- **海量测井数据解析:** 支持高速解析高达数百万行的TXT测井文件，通过流式入库与分页拉取，避免前端挂载极大数据导致的浏览器内存瓶颈。
- **标准别名词典映射 (异构数据洗注):** 针对不同年代不同采集设备导致的文件字段极度繁杂、各异（如 `DEPTH`, `dept`, `测深`, `md` 皆为深度）的问题，系统引入标准列名字典，实现异构文件的统一定义与跨文件联合过滤查询的完美兼容。
- **高性能动态宽表存储:** 摒弃将海量数据完全存内存的传统做法，采用索引指向 + 动态大宽表机制并在核心列（如 DEPTH/AC/DEN/GR）上建立组合索引，极大优化动态条件检索命中率与整体响应性能。并搭配生命周期任务（TTL）自动清理历史过期的大宽表数据。
- **异常地层提取与Echarts联动:** 提供多道测井数据的并行横向Echarts展示。支持阈值条件规则交叉过滤，自动判定并提取连片的地层异常段。系统会自动对其物层厚度进行测算并在可视化图表上借由 `markArea` 高亮渲染，最后支持明细导出。
- **流式打包下载导出:** 为了解决海量数据（几十万条记录）批量导出时的假死问题，采用后端异步流式生成技术（SXSSFWorkbook/ZipOutputStream），边查边压缩并输出网络流，内存控制极佳。
- **AI 智能筛选提取:** 无缝集成阿里云大语言模型（Tongyi LLM），系统自带对话面板。支持自然语言的探区过滤需求输入（如：帮我提取深度在1000-1200米之间，且伽马大于75的所有异常数据），由大模型根据当前文件表头属性返回结构化的高配版规则引擎配置字典，再驱动本地代码完成清洗并提供 Excel 报表。

## 技术选型
### 前端 (Frontend)
- **框架:** Vue 3 (Composition API) + Vite (毫秒级冷启动)
- **UI组件库:** Element Plus
- **状态管理:** Pinia
- **网络请求:** Axios 封装
- **数据可视化:** ECharts

### 后端 (Backend)
- **核心框架:** Spring Boot (现代化的企业级底层支持)
- **ORM / 持久层框架:** MyBatis-Plus 搭配 MyBatis 动态表机制 / Nutz 等组合
- **数据库:** MySQL (存储测井属性字典、鉴权信息和数据大宽表)
- **缓存 & 队列:** Redis (用于分布式会话及短周期的计算缓冲)
- **Excel/文件处理:** Apache POI / Alibaba EasyExcel
- **AI / LLM:** 阿里云大模型 API (DashScope - Qwen)

## 环境要求与开发部署
- **MySQL 8.0+**: 系统依赖 JSON 数据格式及高密度的查询性能。
- **Redis 6.x+**: 须启动 Redis 提供鉴权支撑（已配置至 application.yml）。
- **JDK 17+**: Spring Boot 后端基础运行环境。
- **Node 18+**: 前端 Vite 运行环境要求。

> **提示**：具体系统启动方式可参阅前后端各自目录下的 package.json（执行 
pm run dev） 或 pom.xml。系统后端默认端口 8081，前端采用反向代理路由。
